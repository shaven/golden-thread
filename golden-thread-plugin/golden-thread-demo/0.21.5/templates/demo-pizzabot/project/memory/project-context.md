PizzaBot 3000 is a fictional AI pizza ordering assistant used as the Golden Thread demo project.

**Why:** Demonstrates the full GT workflow (ingest → wiki page → cross-vault query) using material that is obviously fake so audiences don't confuse it with real work.

**How to apply:** Treat all PizzaBot content as demo scaffolding. When demoing, use `/wiki-ingest` with the canned source in `Sources/` to show a live ingest, then query to show cross-vault linking.
