## The session report card

narration: Every habit gt asks for is cheap and easy to skip. The report card looks back at a session and says what was skipped, and in full mode what you are not using yet.
do: Run `bash <scripts>/gt_demo.sh show report-card` and show its output as printed: the card for the demo vault in full mode, then the setting. Read the first finding to the audience in one sentence.
point: Nothing has to remember to check: the card runs at /compact and at session end, and the next session in the same folder shows it.
