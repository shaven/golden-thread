Install Golden Thread

From a bare computer to your first session, about 30 minutes. Each step plays a short animation of what you'll see, and the instructions beside it light up as it goes. Steps you have already done can be skipped.

Each screen carries a badge. Real output is text captured from an actual Mac (macOS 26.6) or Windows 11 machine on 16 October 2026; your version numbers will be the same or newer. Real text means the words are the program's own but the layout is drawn. Drawing is a simplified window.
