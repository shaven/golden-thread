# Inbox

One line per thought, from any session, in any project. No project needed, no
priority, no date. This is the place to put an idea the moment it arrives so you
can go back to what you were doing.

- The rollup (`TASKS.md`) shows every unchecked line here at the very top, under
  **Inbox**, so nothing captured is lost. It does not rank them.
- `/gt:gt-review` reads this file, asks where each line belongs, moves it into that
  project's `## Tasks` (or a new project), and checks the line off here with a
  `→ [[slug]]` pointer. Checked lines are history; delete them whenever you like.
- `[project:: slug]` on a line is a hint for the sweep, nothing more. `[since:: date]`
  is optional; the sweep adds it when it files the task.
